ULTRASKELLYADVANCED (USA) - FIRST BOOT
======================================

1. Power on the Raspberry Pi and wait about two minutes.
2. Join WiFi: UltraSkellyAdvanced-Setup
3. Password: dadtech1
4. Open http://192.168.4.1 if the setup page does not appear automatically.
5. Choose home WiFi or remain on the USA hotspot, accept the disclosure, and
   pair the animatronic.

When connected to home WiFi, use http://usa-controller.local or the address
shown by the router. SSH is disabled and is not required. It can be enabled
with a private password from the dashboard's Diagnostics tab.

The image begins with motion, DAC output, and FPP override disabled. It contains
no API keys, Bluetooth pairings, saved device addresses, or creator account data.
