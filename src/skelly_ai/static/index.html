Required API key permissions

When creating the key in ElevenLabs, enable only:

  • Text to Speech: Access
  • Voices: Read
  • Models: Access
  • User: Access (credit balance)

All other permissions can remain set to No Access.

Credential changes are accepted only from the USA controller's local network. The key is never returned by the API or included in diagnostics.
